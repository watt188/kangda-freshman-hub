# KANGDA / 2026 新生资料库

康复大学 2026 级同学个人整理的新生学习资料站。非官方资料。

## 技术栈
- Next.js App Router
- TypeScript
- React
- Vercel Git Integration

## 本地运行
```bash
npm install
npm run dev
```

## 构建验证
```bash
npm run build
```

## 部署
将仓库导入 Vercel。默认分支 `main` 的每次 push 自动发布 Production；其他分支和 Pull Request 自动生成 Preview Deployment。
